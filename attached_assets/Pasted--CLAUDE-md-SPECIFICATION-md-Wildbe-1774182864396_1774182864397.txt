ШАГ 1 — Новые эндпоинты в server/routes.ts:

1.1 GET /api/wb/orders
Параметры: ?status=new|assembly|delivery|archive|cancelled&storeId=N

Маппинг статусов:
- new: wb_status IN ('new', 'waiting') AND wb_supply_id IS NULL
- assembly: wb_supply_id IS NOT NULL AND wb_status NOT IN ('complete','indelivery','delivering','delivered','cancel','user_cancel','declined')
- delivery: wb_status IN ('complete', 'indelivery', 'delivering')
- archive: wb_status = 'delivered'
- cancelled: wb_status IN ('cancel', 'user_cancel', 'declined')

SQL запрос:
SELECT 
  o.id, o.order_number, o.wb_order_id, o.wb_status,
  o.wb_supply_id, o.wb_rid, o.total_amount, o.created_at,
  s.name as store_name, s.id as store_id,
  oi.quantity, oi.price,
  p.name as product_name, p.sku, p.barcode, p.image_url
FROM orders o
JOIN stores s ON o.store_id = s.id
LEFT JOIN order_items oi ON o.id = oi.order_id
LEFT JOIN products p ON oi.product_id = p.id
WHERE o.source = 'wildberries'
AND o.organization_id = $orgId
ORDER BY o.created_at DESC;

1.2 POST /api/wb/supplies — создать поставку:
Body: { storeId: number, orderIds: number[] }

Логика:
1. Получить cleanApiKey = setting.apiKey.trim()
2. Создать поставку в WB API:
   POST https://marketplace-api.wildberries.ru/api/v3/supplies
   Body: { name: "Поставка " + new Date().toLocaleDateString('ru-RU') }
   Headers: { Authorization: cleanApiKey }
3. Получить supplyId из ответа (поле id)
4. Для каждого заказа добавить в поставку:
   PATCH https://marketplace-api.wildberries.ru/api/v3/supplies/{supplyId}/orders/{wbOrderId}
   Headers: { Authorization: cleanApiKey }
5. Обновить wb_supply_id в orders для всех выбранных заказов
6. Сохранить запись в wb_supplies таблице
7. Вернуть: { supplyId, name, ordersAdded }

1.3 POST /api/wb/stickers — получить стикеры для печати:
Body: { storeId: number, wbOrderIds: number[] }

Логика:
1. Вызвать WB API:
   POST https://marketplace-api.wildberries.ru/api/v3/orders/stickers?type=png&width=58&height=40
   Body: { orders: wbOrderIds }
   Headers: { Authorization: cleanApiKey }
2. Вернуть массив стикеров: [{ orderId, file (base64 PNG) }]

1.4 GET /api/wb/supplies/:supplyId/picking-list — лист подбора:
Вернуть список товаров в поставке:
- Название товара, артикул, штрихкод, количество
Формат: JSON (фронтенд сам распечатает)

1.5 POST /api/wb/supplies/:supplyId/close — закрыть поставку:
Логика:
1. PATCH https://marketplace-api.wildberries.ru/api/v3/supplies/{supplyId}/close
   Headers: { Authorization: cleanApiKey }
2. Обновить статус в wb_supplies: status = 'closed', closedAt = NOW()
3. Вернуть: { success: true }
