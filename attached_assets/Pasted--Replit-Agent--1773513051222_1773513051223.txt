Вот промт — копируй и отправляй в Replit Agent целиком:

**Добавить вкладку «Аналитика» в карточку товара + мини-KPI в списке товаров**

**Фаза 1 — Вкладка «Аналитика» внутри карточки товара**

В компоненте карточки/drawer товара добавь новую вкладку «Аналитика» рядом с существующими вкладками.

Внутри вкладки — три блока:

**Блок 1 — KPI карточки (3 метрики)**
```
┌─────────────────┐ ┌─────────────────┐ ┌─────────────────┐
│ Прибыль FBO     │ │ Прибыль FBS     │ │ Маржа FBO       │
│ 478 ₽           │ │ 379 ₽           │ │ 52%             │
└─────────────────┘ └─────────────────┘ └─────────────────┘
Зелёный цвет если > 0, красный если < 0
```

**Блок 2 — Детальная таблица затрат (FBO и FBS)**

Использовать те же формулы что уже реализованы в Ozon Калькуляторе:
```typescript
// Данные берутся из самого товара — ничего вводить не нужно
const price = product.sellingPrice
const purchasePrice = product.purchasePrice
const commissionPct = product.marketplaceCommission || defaultCommission
const length = product.dimensionLength
const width = product.dimensionWidth  
const height = product.dimensionHeight

// Объём
const volume = (length * width * height) / 1000

// Логистика FBO
const logFBO = volume <= 1 ? 46
  : volume <= 3 ? 46 + (volume - 1) * 10
  : volume <= 190 ? 66 + (volume - 3) * 15
  : 2871

// Логистика FBS  
const logFBS = volume <= 1 ? 80
  : volume <= 3 ? 80 + (volume - 1) * 18
  : volume <= 190 ? 116 + (volume - 3) * 23
  : 4417

const commissionFBO = price * (commissionPct / 100)
const commissionFBS = price * ((commissionPct + 4) / 100) // FBS обычно +4%
const acquiring = price * 0.01
const lastMile = 25
const processingFBS = 30
const tax = price * (taxRate / 100)

const profitFBO = price - commissionFBO - acquiring - logFBO - lastMile - purchasePrice - tax
const profitFBS = price - commissionFBS - acquiring - logFBS - lastMile - processingFBS - purchasePrice - tax
const marginFBO = (profitFBO / price) * 100
const marginFBS = (profitFBS / price) * 100
```

Таблица:
```
Параметр              FBO          FBS
─────────────────────────────────────────
Цена товара           X ₽ 100%    X ₽ 100%
Вознаграждение Ozon   -X ₽ X%     -X ₽ X%
Эквайринг (1%)        -X ₽         -X ₽
Обработка отправления  —           -30 ₽
Логистика             -X ₽         -X ₽
Доставка (последняя миля) -25 ₽   -25 ₽
Себестоимость         -X ₽         -X ₽
Налог (X%)            -X ₽         -X ₽
─────────────────────────────────────────
Чистая прибыль        X ₽ (зел.)  X ₽ (зел.)
Маржинальность        X%           X%
```

**Блок 3 — Симулятор цены**

Под таблицей добавить интерактивный блок:
```
Симулятор цены
Текущая цена: 919 ₽

[ ←────────●──────────→ ]  слайдер от 50% до 200% текущей цены
Новая цена: [  1 200  ] ₽  (редактируемое поле)

При изменении цены — мгновенный пересчёт всей таблицы выше.
Показывать дельту рядом с прибылью:
  Чистая прибыль FBO: 478 ₽ → 720 ₽  (+242 ₽ ↑)  зелёным

Кнопка «Применить цену» — сохраняет новую цену в карточку товара
(PUT /api/products/:id с новым sellingPrice)
```

Если у товара не заполнены габариты — показать жёлтый баннер:
«⚠️ Заполните габариты товара (длина, ширина, высота) для расчёта логистики»
Но KPI по комиссии и налогу всё равно показывать.

---

**Фаза 2 — Мини-KPI в списке товаров**

В таблице товаров (страница Товары) добавить три новые колонки после колонки «Цена»:

```
Прибыль FBO | Прибыль FBS | Маржа
478 ₽        379 ₽         52%
```

Цвета:
- Маржа > 30% → зелёный текст
- Маржа 10–30% → жёлтый текст  
- Маржа < 10% или убыток → красный текст

Колонки кликабельны для сортировки (по прибыли FBO).

Расчёт делать на фронтенде из данных товара — новый API не нужен.

---

**Фаза 3 — Бейдж маржинальности на карточке**

В списке товаров на каждой карточке/строке добавить маленький бейдж рядом с названием товара:

```
● 52%  — зелёный (маржа > 30%)
● 18%  — жёлтый (маржа 10–30%)
● -5%  — красный (убыток или < 10%)
```

Бейдж считается по FBO марже.

---

**Важно:**
- taxRate брать из `GET /api/settings/tax` (уже есть)
- defaultCommission брать из taxSettings.defaultMarketplaceCommission
- Все суммы форматировать: «1 450 ₽» (пробел как разделитель тысяч)
- Если себестоимость = 0 — показывать расчёт но добавить серый текст «Укажите себестоимость для точного расчёта прибыли»
