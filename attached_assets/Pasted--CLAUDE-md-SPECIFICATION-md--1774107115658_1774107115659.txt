Логика расчёта:
- grossRevenue = SUM(order_items.price * quantity) для ВСЕХ заказов
  в диапазоне дат (включая cancelled)
- netRevenue = SUM только для не отменённых
- cancelledRevenue = grossRevenue - netRevenue
- cancellationRate = cancelledRevenue / grossRevenue * 100

Важно для grossRevenue:
Включать ВСЕ статусы без исключения:
- status = 'cancelled' ✓ включать
- ozon_status = 'cancelled' ✓ включать

- моментально отменённые заказы ✓ включать
Исключать только явные дубликаты (одинаковый posting_number + store_id).

3.2 — На графике продаж — два чекбокса над графиком:
☑ Заказано (синий)     ☑ К получению (зелёный)

По умолчанию — оба включены одновременно.

Показывать две линии на одном графике:
- Синяя линия = grossRevenue («Заказано» как в Ozon)
- Зелёная линия = netRevenue («К получению» — реальная выручка)

Визуальный эффект: расстояние между синей и зелёной линиями
наглядно показывает объём отмен за каждый день.
Чем больше разрыв — тем больше отмен в этот день.

Пользователь может:
- Видеть обе линии одновременно (по умолчанию)
- Отключить одну из линий кликом по чекбоксу
- При hover на точке графика показывать tooltip:
  "Заказано: X ₽ | К получению: Y ₽ | Отменено: Z ₽ (N%)"

ШАГ 4 — Проверка после реализации:

Выполни SQL для Сакуры за 18.03:
SELECT 
  ROUND(SUM(CASE WHEN o.status != 'cancelled' 
    AND (o.ozon_status IS NULL OR o.ozon_status != 'cancelled')
    THEN oi.price * oi.quantity ELSE 0 END)::numeric, 0) as net_revenue,
  ROUND(SUM(oi.price * oi.quantity)::numeric, 0) as gross_revenue,
  ROUND(SUM(CASE WHEN o.status = 'cancelled' 
    OR o.ozon_status = 'cancelled'
    THEN oi.price * oi.quantity ELSE 0 END)::numeric, 0) as cancelled_revenue
FROM orders o
JOIN stores s ON o.store_id = s.id
JOIN order_items oi ON o.id = oi.order_id
WHERE s.client_id = '4052691'
AND DATE(o.created_at AT TIME ZONE 'UTC' AT TIME ZONE 'Europe/Moscow') = '2026-03-18';

Ожидаемый результат:
- gross_revenue = 190 929 ₽ ✓
- net_revenue = 163 229 ₽ ✓
- cancelled_revenue = 27 700 ₽ ✓
