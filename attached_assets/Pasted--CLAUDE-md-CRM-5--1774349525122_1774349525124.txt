ШАГ 4 — Исправить syncWbSuppliesForOrg на «Total Mirror»:

Найди в server/routes.ts функцию syncWbSuppliesForOrg.
Покажи текущий код блока MIRROR CLEANUP.

ПРОБЛЕМА: Сейчас cleanup разбит на два блока:
- if (resolvedStoreId !== null) → cleanup для известного store
- отдельный блок для store_id IS NULL

Это создаёт race condition — поставки «воскресают»
потому что upsert логика может вернуть им status='open'.

ЗАМЕНИТЬ оба блока на единый «Total Mirror»:

// TOTAL MIRROR — единственная логика (убрать все if по store_id):
// Срабатывает всегда при успешном ответе от WB API (status 200)
if (activeSupplyIds !== null) {
  // Получить ВСЕ open поставки этой организации:
  const allOpenRows = await db.execute(sql`
    SELECT supply_id FROM wb_supplies
    WHERE status = 'open'
    AND organization_id = ${orgId}
  `);
  const allOpen: any[] = (allOpenRows as any).rows || allOpenRows;

  // Закрыть те которых нет в WB API ответе:
  const toClose = allOpen
    .map((r: any) => String(r.supply_id))
    .filter((id: string) => !activeSupplyIds!.has(id));

  if (toClose.length > 0) {
    for (const sid of toClose) {
      await db.execute(sql`
        UPDATE wb_supplies
        SET status = 'closed', closed_at = NOW()
        WHERE supply_id = ${sid}
        AND status = 'open'
        AND organization_id = ${orgId}
      `);
    }
    console.log(
      `[wb-supply-sync] ${displayName}: закрыто устаревших: ${toClose.length}`
    );
  }

  console.log(
    `[wb-supply-sync] ${displayName}: ` +
    `${activeSupplyIds.size} активных в WB, ` +
    `закрыто: ${toClose.length}`
  );
}

ВАЖНО: удалить старые блоки
if (resolvedStoreId !== null) { ... cleanup ... }
и блок for store_id IS NULL.
Оставить только один Total Mirror блок выше.
