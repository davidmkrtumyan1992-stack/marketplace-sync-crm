Task: Полный редизайн интерфейса Wildberries FBS под стандарт «Зеркало» (WB Seller API)

Прочитай CLAUDE.md и SPECIFICATION.md для контекста.
Цель: Привести интерфейс WildberriesOrders.tsx к 100% визуальному и логическому соответствию с личным кабинетом WB Seller (на основе предоставленных описаний скриншотов).

ОБЩИЕ ПРАВИЛА:

UI: Белый фон таблиц, тонкие светлые границы, фиолетовый акцент #7631ff для кнопок.

Логика: cleanApiKey = setting.apiKey.trim() во всех запросах. Разделитель тысяч в числах — пробел. Кавычки — «елочки».

Библиотеки: Если xlsx не установлена, выполнить npm install xlsx.

Пустые состояния: Если данных нет, показывать иконку (Lucide PackageSearch) и текст «У вас пока нет заказов в этом статусе».

1. БЭКЕНД — Исправления эндпоинтов
ИСПРАВЛЕНИЕ «НОВЫЕ»: В GET /api/wb/orders?status=new показывать только заказы wb_status IN ('new', 'waiting') за последние 72 часа. Старые заказы скрывать.

СИНХРОНИЗАЦИЯ АРХИВА: В GET /api/wb/orders?status=archive, если в БД < 100 записей, выполнить запрос к WB API (/api/v3/orders) за последние 30 дней со статусом sold. Сохранить результаты в БД.

ЭНДПОИНТ ПОСТАВОК: Создать GET /api/wb/supplies для получения списка из таблицы wb_supplies. Добавить LEFT JOIN к orders, чтобы вернуть orders_count (количество заказов в каждой поставке).

УПРАВЛЕНИЕ: Реализовать PATCH /api/wb/supplies/:supplyId/rename (API WB + локальная БД).

2. ФРОНТЕНД — Редизайн WildberriesOrders.tsx
ВКЛАДКА «НОВЫЕ» (Таблица заказов):

Колонка «Заказ»: Жирный номер задания. Снизу дата и время (серым). Бейджи: зеленый «X ч Y мин назад» и серый прямоугольный «МГТ».

Колонка «Товар»: Квадратное фото 48px. Справа Название товара, под ним серым: «Бренд / Артикул». Если фото нет — иконка-заглушка.

Колонка «Стоимость»: Цена в формате 1 450 ₽.

Колонка «Склад»: Текст «Мой склад», под ним store_name.

Меню «···»: Печать этикетки, Отменить заказ.

Панель: Внизу sticky-блок «Выбрано N [Создать поставку]» (фиолетовая кнопка).

ВКЛАДКА «НА СБОРКЕ» (Список ПОСТАВОК):

Показать список из GET /api/wb/supplies со статусом open.

Колонки: 1. Поставка: Название («Поставка от...»), ниже ID (WB-GI-...), бейдж «МГТ».
2. QR-код поставки: Текст supply_id.
3. Заказы / Грузоместа: {count} / 1 грузоместо.
4. Этап сборки: Оранжевый бейдж «Ждёт передачи в доставку».
5. Склад: store_name.

Меню «···»: Печать стикеров, Лист подбора (PDF/Excel/Экран), Переименовать, Закрыть поставку.

ВКЛАДКА «В ДОСТАВКЕ» (Список ПОСТАВОК):

Показать поставки со статусом closed.

Колонки: Поставка, QR-код, Статус (синий бейдж «Поставка в обработке»), Время сканирования (из closed_at), Заказы/Грузоместа, Склад.

ВКЛАДКА «АРХИВ» (Таблица заказов):

Заказы со статусами delivered, sold.

Колонки: Заказ, Товар, Стоимость, Склад, Статус (синяя кнопка-ссылка «Отсортировано ›»), Номер стикера (wb_rid), Время доставки.

ВКЛАДКА «ОТМЕНЁННЫЕ»:

Сверху: Желтая плашка-предупреждение об остатках с фиолетовой кнопкой «Перейти в управление остатками» (линк на /inventory).

Колонки: Заказ, Товар, Стоимость, Склад, Баркод, Причина отмены.
