Добавить «Ozon Калькулятор» в раздел Товары
1. Кнопка в шапке страницы Товары
Рядом с кнопкой «Добавить товар» добавь кнопку с иконкой калькулятора и текстом «Ozon Калькулятор». Иконка — Calculator из lucide-react. Стиль кнопки — outline (не заливка), цвет акцентный.
2. При нажатии — открывается Dialog (модальное окно)
Заголовок: «Ozon Калькулятор» с иконкой Calculator.
Внутри два блока — слева форма ввода, справа результат.
Форма ввода (левая часть):
Поиск товара из CRM (необязательно):
- Поле поиска по штрихкоду или названию — при выборе товара 
  автоматически заполняет поля ниже

Параметры товара:
- Цена продажи (₽) — число, обязательное
- Себестоимость (₽) — число
- Комиссия Ozon (%) — число, default 15
- Длина (см) — число
- Ширина (см) — число  
- Высота (см) — число

Налог берётся автоматически из настроек организации (taxRate).

Кнопка «Рассчитать» — большая, акцентная
Результат (правая часть) — показывается после нажатия «Рассчитать»:
Таблица в стиле Ozon, два столбца FBO и FBS:
┌─────────────────────────┬──────────┬──────────┐
│                         │   FBO    │   FBS    │
├─────────────────────────┼──────────┼──────────┤
│ Цена товара             │ X ₽ 100% │ X ₽ 100% │
│ Вознаграждение Ozon     │ -X ₽  X% │ -X ₽  X% │
│ Эквайринг (1.5%)        │ -X ₽     │ -X ₽     │
│ Логистика               │ -X ₽     │ -X ₽     │
│ Последняя миля (5.5%)   │ -X ₽     │ -X ₽     │
│ Себестоимость           │ -X ₽     │ -X ₽     │
│ Налог (X%)              │ -X ₽     │ -X ₽     │
├─────────────────────────┼──────────┼──────────┤
│ Чистая прибыль          │ X ₽      │ X ₽      │
│ Маржинальность          │ X%       │ X%       │
└─────────────────────────┴──────────┴──────────┘
Прибыль: зелёная если > 0, красная если < 0.
Если габариты не заполнены — логистику показать как «—» и добавить жёлтую подсказку «Введите габариты для расчёта логистики».
3. Логика расчёта (фронтенд, без нового API-эндпоинта):
объём (л) = длина × ширина × высота / 1000

FBO логистика:
  объём ≤ 1 → 46
  объём ≤ 3 → 46 + (объём - 1) × 10
  объём ≤ 190 → 66 + (объём - 3) × 15
  объём > 190 → 2871

FBS логистика:
  объём ≤ 1 → 80
  объём ≤ 3 → 80 + (объём - 1) × 18
  объём ≤ 190 → 116 + (объём - 3) × 23
  объём > 190 → 4417

lastMile = min(цена × 0.055, 500)
комиссия = цена × (commissionPct / 100)
эквайринг = цена × 0.015
налог = цена × (taxRate / 100)

totalFBO = комиссия + эквайринг + logisticsFBO + lastMile + себестоимость + налог
totalFBS = комиссия + эквайринг + logisticsFBS + lastMile + себестоимость + налог

profitFBO = цена - totalFBO
profitFBS = цена - totalFBS
marginFBO = (profitFBO / цена) × 100
marginFBS = (profitFBS / цена) × 100
Расчёт происходит на фронтенде — новый API не нужен, только GET /api/settings/tax для получения ставки налога (уже есть).
Все числа форматировать с пробелом как разделителем тысяч: «1 450 ₽».
Внизу серый текст: «Расчёт приблизительный. Тарифы актуальны на 2025 год и могут измениться.»
