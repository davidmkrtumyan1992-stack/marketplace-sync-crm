СРОЧНОЕ ИСПРАВЛЕНИЕ: После синхронизации «На сборке» показывает 
152 поставки хотя в ЛК WB их 0.

Проблема: WB API возвращает ВСЕ открытые поставки включая
пустые (без заказов). ЛК WB в разделе «На сборке» показывает
только поставки у которых есть заказы ожидающие сборки.

ШАГ 1 — Диагностика:

-- Сколько поставок имеют реальные заказы:
SELECT 
  ws.supply_id,
  ws.status,
  COUNT(o.id) as orders_count
FROM wb_supplies ws
LEFT JOIN orders o ON o.wb_supply_id = ws.supply_id
  AND o.source = 'wildberries'
  AND o.wb_status NOT IN ('cancel','user_cancel','declined','cancelled')
WHERE ws.status = 'open'
GROUP BY ws.supply_id, ws.status
ORDER BY orders_count DESC
LIMIT 20;

-- Сколько поставок пустые (нет заказов):
SELECT COUNT(*) as empty_supplies
FROM wb_supplies ws
WHERE ws.status = 'open'
AND NOT EXISTS (
  SELECT 1 FROM orders o 
  WHERE o.wb_supply_id = ws.supply_id
  AND o.source = 'wildberries'
);

Покажи результаты.
