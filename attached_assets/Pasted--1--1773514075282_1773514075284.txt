Вижу два бага и одно упущение. Вот анализ и промт для исправления:

**Баг 1** — в карточке товара нет полей для габаритов (длина/ширина/высота/вес). Они есть в БД (`dimensionLength`, `dimensionWidth`, `dimensionHeight` в schema.ts) но не добавлены в форму редактирования.

**Баг 2** — кнопка «Применить цену» падает с ошибкой. Скорее всего отправляет неправильное тело запроса на `PUT /api/products/:id`.

Вот промт для Replit:

---

**Исправить два бага в карточке товара и вкладке Аналитика**

**Баг 1 — добавить поля габаритов в форму карточки товара**

В компоненте карточки/формы товара (вкладка «Информация») добавь поля после поля «Цена продажи»:

```
Габариты товара (для расчёта логистики Ozon)
┌─────────────┐ ┌─────────────┐ ┌─────────────┐ ┌─────────────┐
│ Длина (см)  │ │ Ширина (см) │ │ Высота (см) │ │  Вес (кг)   │
│ number input│ │ number input│ │ number input│ │ number input│
└─────────────┘ └─────────────┘ └─────────────┘ └─────────────┘
```

Эти поля уже есть в БД: `dimension_length`, `dimension_width`, `dimension_height`, `weight`. Просто добавить в форму и включить в PUT запрос при сохранении.

Добавить также поле «Комиссия маркетплейса (%)» если его нет в форме — поле `marketplace_commission` в БД уже есть.

**Баг 2 — исправить кнопку «Применить цену» в симуляторе**

Кнопка «Применить цену» падает с ошибкой «не удалось обновить цену». Исправить запрос:

```typescript
// Правильный запрос:
const response = await fetch(`/api/products/${product.id}`, {
  method: 'PUT',
  headers: { 'Content-Type': 'application/json' },
  credentials: 'include',
  body: JSON.stringify({ 
    sellingPrice: String(newPrice),  // важно: передавать как строку, так хранится в БД
    price: String(newPrice)          // обновить оба поля
  })
});

if (!response.ok) {
  const err = await response.json();
  throw new Error(err.message || 'Ошибка');
}

// После успешного сохранения — обновить кэш TanStack Query:
queryClient.invalidateQueries({ queryKey: ['/api/products'] });
```

После применения цены показывать toast «✓ Цена обновлена» и обновлять отображение текущей цены в симуляторе.

**Баг 3 — вознаграждение FBS считается неправильно**

Сейчас FBS комиссия = FBO% + 4%. Это неточно. Исправить:

```typescript
// В утилите расчёта:
const commissionFBO = price * (commissionPct / 100)
// FBS комиссия берётся из отдельного поля или +4% если не задана
const commissionFBS = price * ((Number(product.marketplaceCommissionFbs) || commissionPct + 4) / 100)
```

Если отдельного поля для FBS комиссии нет — добавить поле `commissionFbsPct` в форму рядом с полем комиссии FBO с подписью «FBO %» и «FBS %».
