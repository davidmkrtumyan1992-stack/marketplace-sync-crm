ШАГ 2 — Маппинг статусов WB в server/routes.ts:

Добавить функцию wbStatusToInternal:
function wbStatusToInternal(wbStatus: string): string {
  switch (wbStatus) {
    case 'new':
    case 'waiting':
      return 'pending';
    case 'confirm':
    case 'complete':
    case 'indelivery':
    case 'delivering':
      return 'shipped';
    case 'delivered':
    case 'receive':
      return 'completed';
    case 'cancel':
    case 'user_cancel':
    case 'declined':
      return 'cancelled';
    default:
      return 'pending';
  }
}

ШАГ 3 — Новый эндпоинт синхронизации WB заказов:

Добавить POST /api/marketplace/wildberries/sync-orders
по аналогии с существующим /api/marketplace/ozon/sync-orders.

Логика:
1. Получить все активные WB настройки из marketplace_settings
   где marketplace = 'wildberries' и isActive = true

2. Для каждого магазина:

   // Временной диапазон — Золотой стандарт МСК:
   const since = new Date();
   since.setUTCHours(21, 0, 0, 0);
   since.setUTCDate(since.getUTCDate() - 1);
   const to = new Date();
   to.setUTCHours(21, 0, 0, 0);

   // Получить НОВЫЕ заказы:
   GET https://marketplace-api.wildberries.ru/api/v3/orders/new
   Headers: { Authorization: apiKey }

   // Получить ВСЕ заказы за период:
   GET https://marketplace-api.wildberries.ru/api/v3/orders
   ?limit=1000&next=0&dateFrom={since.getTime()/1000}&dateTo={to.getTime()/1000}
   Headers: { Authorization: apiKey }

3. Для каждого заказа из API:
   - Проверить существует ли уже (по wbOrderId + storeId)
   - Если нет — создать новый заказ в orders
   - Если есть — обновить wbStatus

4. Маппинг полей WB заказа → orders:
   orderNumber: order.id.toString()
   wbOrderId: order.id.toString()
   wbStatus: order.wbStatus или order.status
   wbRid: order.rid
   wbSupplyId: order.supplyId || null
   source: 'wildberries'
   status: wbStatusToInternal(order.wbStatus)
   totalAmount: order.totalPrice / 100  -- WB передаёт в копейках!
   storeId: resolvedStoreId
   organizationId: orgId
   createdAt: new Date(order.createdAt * 1000) -- Unix timestamp!

5. Для order_items:
   productId: найти по article (артикул товара) через getProductBySku
   quantity: order.quantity или 1
   price: order.convertedPrice / 100

6. Обновить stores.lastSync после успешной синхронизации

7. Вернуть результат:
   { storeName, created, updated, errors }
