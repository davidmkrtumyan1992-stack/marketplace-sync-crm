   Headers: { Authorization: cleanApiKey }
4. Обновить в БД: wb_status = 'user_cancel', status = 'cancelled'

БАГ 2 — Вкладка «В доставке» пустая
═══════════════════════════════════════

Проблема: поставки есть в WB но не отображаются в CRM.

Диагностика — выполни SQL:
SELECT ws.supply_id, ws.name, ws.status, ws.created_at
FROM wb_supplies ws
WHERE ws.organization_id = (
  SELECT organization_id FROM marketplace_settings 
  WHERE marketplace = 'wildberries' LIMIT 1
)
ORDER BY ws.created_at DESC
LIMIT 10;

Если таблица пустая — значит поставки никогда не синхронизировались.
Нужно подтянуть поставки из WB API:

Добавить эндпоинт POST /api/wb/supplies/sync — синхронизация поставок:
1. Для каждого WB магазина:
   
   // Получить открытые поставки:
   GET https://marketplace-api.wildberries.ru/api/v3/supplies
   ?limit=1000&next=0&status=ACTIVE
   Headers: { Authorization: cleanApiKey }
   
   // Получить закрытые поставки:
   GET https://marketplace-api.wildberries.ru/api/v3/supplies
   ?limit=1000&next=0&status=CLOSED
   Headers: { Authorization: cleanApiKey }

2. Для каждой поставки из API сохранить в wb_supplies:
   - supply_id: supply.id (строка WB-GI-...)
   - name: supply.name
   - status: supply.done ? 'closed' : 'open'
   - store_id: resolvedStoreId
   - organization_id: orgId
   Использовать INSERT ... ON CONFLICT (supply_id) DO UPDATE

3. Для каждой поставки получить заказы:
   GET https://marketplace-api.wildberries.ru/api/v3/supplies/{supplyId}/orders
   Headers: { Authorization: cleanApiKey }
   
   Обновить wb_supply_id в orders для этих заказов.

4. Вернуть: { synced: N }

Добавить кнопку «↻ Синхронизировать поставки» вверху вкладок
«На сборке» и «В доставке» — вызывает POST /api/wb/supplies/sync.

После синхронизации — обновить список поставок.

Меню ··· для вкладки «В доставке»:
- Печать стикера поставки

БАГ 4 — Вкладка «Отменённые» — ошибка
═══════════════════════════════════════

Покажи точную ошибку из консоли браузера и из логов сервера.
Выполни SQL:
SELECT wb_status, COUNT(*) 
FROM orders 
WHERE source = 'wildberries' 
AND wb_status IN ('cancel', 'user_cancel', 'declined', 'cancelled')
GROUP BY wb_status;

Исправь фильтр статусов для вкладки «Отменённые» — 
добавить все возможные варианты отмены WB:
wb_status IN ('cancel', 'user_cancel', 'declined', 'cancelled', 'cancel_ignore')
OR status = 'cancelled' AND source = 'wildberries'
